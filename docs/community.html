Where it is honest to say we are

A new protocol is evaluated differently from an established one, and pretending otherwise helps nobody. MSD does not have a long adopter list, and the places using it today are few.

What it does have is a working implementation, a public SDK, and a model that answers a question most provenance tooling leaves open: which parts of a data trail can you check for yourself, and which parts rest on somebody's signature.

If you are evaluating it for production use, that distinction is probably the thing worth testing first.

# docs/

A single self-contained explainer page, `index.html` — no build step, no external requests,
no dependencies. Open it directly in a browser, or publish it with GitHub Pages
(Settings → Pages → Deploy from branch → `main` / `/docs`).

It explains the provenance model in plain language for a non-technical reader: which steps
in a data pipeline an auditor can verify independently, and which rest on a signature.

Draft for discussion, not a product specification.
